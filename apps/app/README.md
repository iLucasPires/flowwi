# FlowWi App

Frontend Vue 3 + Vite do [FlowWi](../../README.md).

Convenções de componentes, composables, auto-imports e roteamento estão em [AGENTS.md](AGENTS.md).

```bash
pnpm install
pnpm dev          # servidor de desenvolvimento
pnpm build        # build de produção
pnpm test:unit    # testes (Vitest)
pnpm lint         # lint (ESLint)
```
